Начните за пять минут

Быстрый старт.

От загрузки до первого трека: для локальной библиотеки не нужны ни учётная запись, ни сервер.

Подробное руководство в вики ↗
  1. 1 минутаУстановите и откройте

    Скачайте пакет для своей операционной системы, установите Orynivo и запустите приложение.

  2. 1 минутаДобавьте источник музыки

    Откройте Настройки → Папки и выберите хотя бы одну локальную музыкальную папку. Вместо неё или дополнительно можно подключить сервер Orynivo.

  3. АвтоматическиПросканируйте библиотеку

    Запустите сканирование. Исполнители, альбомы, треки и имеющиеся обложки будут появляться по мере индексации.

  4. 1 минутаПроверьте аудиовыход

    Выход по умолчанию работает сразу. При необходимости выберите WASAPI, ASIO, ALSA, OpenAL или AirPlay в Настройки → Вывод.

  5. Всё готовоВключите первый трек

    Откройте Треки, Альбомы или Исполнители и дважды щёлкните трек. Громкость, очередь и выход всегда доступны в нижней панели проигрывателя.

Установка для вашей платформы

Подходящий пакет для вашей системы.

  1. Скачать установщикСкачайте актуальный файл win-x64-Setup.exe со страницы выпуска.
  2. Установите OrynivoЗапустите установщик и следуйте указаниям мастера. Также можно распаковать переносимый ZIP-архив.
  3. Добавьте музыкуОткройте Настройки → Библиотека, добавьте музыкальные папки и запустите сканирование.
  4. Выберите выходOrynivo выбирает выход по умолчанию. Для побитово точного воспроизведения настройте WASAPI Exclusive, ASIO или cwASIO.
  1. Выберите пакетИспользуйте DEB для Debian/Ubuntu, RPM для Fedora/openSUSE или пакет Arch. Также доступны переносимые tar-архивы.
  2. Установитьsudo apt install ./orynivo_*.deb
    sudo dnf install ./orynivo-*.rpm
    sudo pacman -U ./orynivo-*.pkg.tar.zst
  3. Подготовьте аудиоНеобходим FFmpeg. OpenAL обеспечивает совместимый стандартный вывод; прямой ALSA позволяет использовать эксклюзивный вывод и нативный DSD/DoP.
  1. Выберите архитектуруApple Silicon для M1 и новее, Intel для более старых Mac.
  2. Откройте PKGОткройте пакет из подписанного выпуска и установите Orynivo в папку «Программы». Также доступны переносимые ZIP- и tar-архивы.
  3. Просканируйте библиотекуДобавьте музыкальные папки. Orynivo ищет FFmpeg в стандартных каталогах менеджеров пакетов и в пользовательском кэше.
  1. Установите серверный пакетУстановите подходящий пакет DEB или RPM в Linux.
  2. Измените конфигурациюУкажите API-ключ и пути к библиотеке в /etc/orynivo-server/appsettings.json . Не публикуйте ключ.
  3. Запустите службуsudo systemctl enable --now orynivo-server
  4. Подключите клиентДобавьте сервер в Orynivo в Настройки → Серверы Orynivo. Порт по умолчанию: 5280.

Полезно знать

Частые вопросы.

Orynivo действительно бесплатен?

Да. Orynivo распространяется по лицензии Apache 2.0. Вы можете бесплатно пользоваться проигрывателем, изучать его код и дорабатывать его.

Какие аудиоформаты поддерживаются?

В том числе FLAC, WAV, MP3, AAC, Ogg/Vorbis, Opus, MKA, DSF и несжатый DFF/DSDIFF. Декодирование некоторых форматов зависит от FFmpeg.

Нужен ли мне Orynivo Server?

Нет. Для локальной библиотеки достаточно настольного приложения. Необязательный сервер предоставляет общую коллекцию клиентам Orynivo в локальной сети.

Отправляет ли Orynivo мою библиотеку в облако?

Нет. Библиотека и настройки остаются локально. Внешние службы используются только для явно выбранных функций: метаданных, радио, подкастов или чата с ИИ.

Как получать обновления?

Orynivo проверяет подписанные выпуски GitHub. Загрузка и установка начинаются только по вашему явному действию. Этот сайт обращается только к общедоступному API выпусков GitHub, чтобы показать актуальные ссылки на загрузку.
