Готово за пять минут

Ваш быстрый старт.

От загрузки до первого трека: локальной библиотеке не требуется ни учетная запись, ни сервер.

Полное руководство в вики ↗
  1. 1 минутаУстановить и открыть

    Загрузите пакет для вашей операционной системы, установите Orynivo и запустите приложение.

  2. 1 минутаДобавить источник музыки

    Откройте «Настройки» → «Каталоги» и выберите хотя бы одну локальную папку с музыкой. Вместо этого или в дополнение вы можете подключить Сервер Orynivo.

  3. АвтоматическийСканируйте свою библиотеку

    Запустите сканирование. Исполнители, альбомы, треки и существующие иллюстрации появляются постепенно во время индексации.

  4. 1 минутаПроверьте аудиовыход

    Вывод по умолчанию работает немедленно. В разделе «Настройки» → «Вывод» вы можете выбрать WASAPI, ASIO, ALSA, OpenAL или AirPlay, когда это необходимо.

  5. ГотовыйВключи свой первый трек

    Откройте «Треки», «Альбомы» или «Исполнители» и дважды щелкните трек. Громкость, очередь и вывод остаются доступными в нижнем плеере.

Установка для конкретной платформы

Подходящий пакет для вашей системы.

  1. Загрузите установщикЗагрузите текущую win-x64-Setup.exe из релиза.
  2. Установить ОрынивоЗапустите установщик и следуйте указаниям мастера. Альтернативно распакуйте портативный ZIP-файл.
  3. Добавить музыкуОткройте «Настройки» → «Библиотека», добавьте папки с музыкой и запустите сканирование.
  4. Выберите выходOrynivo выбирает выход по умолчанию. Для идеального воспроизведения настройте WASAPI Exclusive, ASIO или cwASIO.
  1. Выберите пакетИспользуйте DEB для Debian/Ubuntu, RPM для Fedora/openSUSE или пакет Arch. Также доступны портативные архивы.
  2. Установитьsudo apt install ./orynivo_*.deb
    sudo dnf install ./orynivo-*.rpm
    sudo pacman -U ./orynivo-*.pkg.tar.zst
  3. Подготовьте аудиоТребуется FFmpeg. OpenAL является совместимым по умолчанию; Direct ALSA обеспечивает эксклюзивный вывод и собственный DSD/DoP.
  1. Выберите архитектуруApple Silicon для M1 и новее, Intel для старых компьютеров Mac.
  2. Откройте ПКГОткройте подписанный пакет выпуска и установите Orynivo в разделе «Приложения». Также доступны портативные версии ZIP и tar.
  3. Сканируйте свою библиотекуДобавьте музыкальные папки. Orynivo ищет FFmpeg в общих путях менеджера пакетов и пользовательском кеше.
  1. Установите серверный пакетУстановите соответствующий пакет DEB или RPM в системе Linux.
  2. Изменить конфигурациюВведите ключ API и пути к библиотеке в /etc/orynivo-server/appsettings.json . Не делитесь ключом публично.
  3. Запустить службуsudo systemctl enable --now orynivo-server
  4. Подключите клиентДобавьте сервер в Orynivo в разделе «Настройки» → «Сервер Orynivo». Порт по умолчанию: 5280.

Приятно знать

Часто задаваемые вопросы.

Действительно ли Орыниво бесплатен?

Да. Orynivo выпускается под лицензией Apache 2.0. Вы можете использовать, проверять и развивать плеер бесплатно.

Какие аудиоформаты поддерживаются?

Включая FLAC, WAV, MP3, AAC, Ogg/Vorbis, Opus, MKA, DSF и несжатый DFF/DSDIFF. Точная поддержка декодирования частично зависит от FFmpeg.

Нужен ли мне сервер Orynivo?

Нет. Для локальной библиотеки достаточно настольного приложения. Дополнительный сервер делает центральную коллекцию доступной для клиентов Orynivo в вашей локальной сети.

Отправляет ли Orynivo мою библиотеку в облако?

Нет. Ваша библиотека и настройки остаются локальными. К внешним службам обращаются только для функций, которые вы явно используете, таких как метаданные, радио, подкасты или чат с искусственным интеллектом.

Как мне получать обновления?

Orynivo может проверять подписанные выпуски GitHub. Загрузка и установка начнутся только после вашего явного действия. Этот веб-сайт также использует только общедоступный API-интерфейс GitHub Releases для отображения текущих ссылок для скачивания.
