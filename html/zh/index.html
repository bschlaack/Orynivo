五分钟快速上手

快速开始。

从下载到播放第一首曲目，本地媒体库无需账户或服务器。

Wiki 中的完整指南 ↗
  1. 1 分钟安装并打开

    下载适合您操作系统的软件包，安装并启动 Orynivo。

  2. 1 分钟添加音乐来源

    打开“设置 → 目录”，选择至少一个本地音乐文件夹。也可连接 Orynivo 服务器作为替代或补充。

  3. 自动扫描媒体库

    启动扫描。艺术家、专辑、曲目和已有封面会随索引过程逐步显示。

  4. 1 分钟检查音频输出

    默认输出可直接使用。如有需要，可在“设置 → 输出”中选择 WASAPI、ASIO、ALSA、OpenAL 或 AirPlay。

  5. 开始聆听播放第一首曲目

    打开“曲目”“专辑”或“艺术家”，双击一首曲目。音量、队列和输出始终可在底部播放器中操作。

选择适合您系统的软件包。

  1. 下载安装程序从发行页面下载最新的 win-x64-Setup.exe 文件。
  2. 安装 Orynivo运行安装程序并按向导操作，也可解压便携版 ZIP。
  3. 添加音乐打开“设置 → 媒体库”，添加音乐文件夹并启动扫描。
  4. 选择输出Orynivo 会选择默认输出。若需位完美播放，可配置 WASAPI 独占模式、ASIO 或 cwASIO。
  1. 选择软件包Debian/Ubuntu 使用 DEB，Fedora/openSUSE 使用 RPM，Arch 使用对应软件包。也提供便携版 tar 压缩包。

  3. 配置音频需要 FFmpeg。OpenAL 为兼容性良好的默认输出；直接 ALSA 支持独占输出和原生 DSD/DoP。
  1. 选择架构M1 及更新机型选择 Apple Silicon，较旧的 Mac 选择 Intel。
  2. 打开 PKG打开发行版本中的签名软件包，将 Orynivo 安装到“应用程序”。也提供便携版 ZIP 和 tar 压缩包。

实用信息

常见问题。

Orynivo 真的免费吗？

是的。Orynivo 采用 Apache 2.0 许可证。您可以免费使用、审查和改进播放器。

支持哪些音频格式？

包括 FLAC、WAV、MP3、AAC、Ogg/Vorbis、Opus、MKA、DSF 和未压缩的 DFF/DSDIFF。部分格式的解码依赖 FFmpeg。

需要 Orynivo Server 吗？

不需要。本地媒体库只需桌面应用。服务器为可选组件，用于在局域网中向 Orynivo 客户端提供集中式音乐收藏。

Orynivo 会将媒体库上传到云端吗？

不会。媒体库和设置保留在本地。仅在您主动使用元数据、电台、播客或 AI 聊天等功能时，才会连接外部服务。

如何获取更新？

Orynivo 可检查带签名的 GitHub 发行版本。只有您主动操作后才会下载和安装。本网站也仅访问公共 GitHub Releases API，以显示最新下载链接。
