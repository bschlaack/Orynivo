维基百科中的完整指南 ↗
  1. 1分钟安装并打开

    下载适合您的操作系统的软件包，安装 Orynivo 并启动该应用程序。

  2. 1分钟添加音乐源

    打开设置 → 目录并选择至少一个本地音乐文件夹。您可以替代或另外连接 Orynivo 服务器。

  3. 自动的扫描您的图书馆

    开始扫描。索引运行时，艺术家、专辑、曲目和现有艺术作品会逐渐出现。

  4. 1分钟检查音频输出

    默认输出立即生效。在“设置”→“输出”下，您可以根据需要选择 WASAPI、ASIO、ALSA、OpenAL 或 AirPlay。

  5. 准备好播放您的第一首曲目

    打开曲目、专辑或艺术家，然后双击曲目。音量、队列和输出在底部播放器中仍然可用。

常见问题。

Orynivo 真的免费吗？

是的。 Orynivo 是根据 Apache 2.0 许可证发布的。您可以免费使用、检查和开发该播放器。

支持哪些音频格式？

包括 FLAC、WAV、MP3、AAC、Ogg/Vorbis、Opus、MKA、DSF 和未压缩的 DFF/DSDIFF。确切的解码支持部分取决于 FFmpeg。

我需要 Orynivo 服务器吗？

不需要。桌面应用程序对于本地图书馆来说已经足够了。可选服务器使本地网络上的 Orynivo 客户端可以使用中央集合。

Orynivo 是否会将我的图书馆发送到云端？

不会。您的库和设置仍保留在本地。仅针对您明确使用的功能（例如元数据、广播、播客或 AI 聊天）联系外部服务。

我如何获取更新？

Orynivo 可以检查签名的 GitHub 版本。仅在您明确执行操作后才会开始下载和安装。该网站还仅使用公共 GitHub Releases API 来显示当前的下载链接。
