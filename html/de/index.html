In fünf Minuten startklar

Dein Schnellstart.

Vom Download bis zum ersten Titel: Für eine lokale Bibliothek brauchst du weder ein Konto noch einen Server.

Ausführliche Anleitung in der Wiki ↗
  1. 1 MinuteInstallieren und öffnen

    Lade das Paket für dein Betriebssystem herunter, installiere Orynivo und starte die App.

  2. 1 MinuteMusikquelle hinzufügen

    Öffne Einstellungen → Verzeichnisse und wähle mindestens einen lokalen Musikordner. Einen Orynivo Server kannst du stattdessen oder zusätzlich verbinden.

  3. AutomatischBibliothek einlesen

    Starte den Scan. Künstler, Alben, Tracks und vorhandene Cover erscheinen während der Indexierung nach und nach.

  4. 1 MinuteAudioausgang prüfen

    Der Standardausgang funktioniert sofort. Unter Einstellungen → Ausgabe kannst du bei Bedarf WASAPI, ASIO, ALSA, OpenAL oder AirPlay auswählen.

  5. Los geht’sErsten Titel abspielen

    Öffne Tracks, Alben oder Künstler und doppelklicke auf einen Titel. Lautstärke, Warteschlange und Ausgang findest du dauerhaft im unteren Player.

Plattformspezifische Installation

Das passende Paket für dein System.

  1. Installer ladenLade die aktuelle win-x64-Setup.exe aus dem Release herunter.
  2. Orynivo installierenStarte den Installer und folge dem Assistenten. Alternativ kannst du das portable ZIP entpacken.
  3. Musik hinzufügenÖffne Einstellungen → Bibliothek, füge deine Musikordner hinzu und starte den Scan.
  4. Ausgang wählenOrynivo wählt einen Standardausgang. Für bitperfekte Wiedergabe kannst du WASAPI Exclusive, ASIO oder cwASIO konfigurieren.
  1. Paket wählenNutze DEB für Debian/Ubuntu, RPM für Fedora/openSUSE oder das Arch-Paket. Portable Tarballs stehen ebenfalls bereit.
  2. Installierensudo apt install ./orynivo_*.deb
    sudo dnf install ./orynivo-*.rpm
    sudo pacman -U ./orynivo-*.pkg.tar.zst
  3. Audio vorbereitenFFmpeg wird benötigt. OpenAL ist der kompatible Standard; Direct ALSA ermöglicht exklusive Ausgabe und natives DSD/DoP.
  1. Architektur wählenApple Silicon für M1 und neuer, Intel für ältere Macs.
  2. PKG öffnenÖffne das signierte Release-Paket und installiere Orynivo nach Programme. Portable ZIP- und Tar-Versionen sind ebenfalls verfügbar.
  3. Bibliothek einlesenFüge Musikordner hinzu. Orynivo sucht FFmpeg in üblichen Paketmanager-Pfaden und im Benutzer-Cache.
  1. Serverpaket installierenInstalliere das passende DEB- oder RPM-Paket auf einem Linux-System.
  2. Konfiguration bearbeitenTrage API-Schlüssel und Bibliothekspfade in /etc/orynivo-server/appsettings.json ein. Teile den Schlüssel nicht öffentlich.
  3. Dienst startensudo systemctl enable --now orynivo-server
  4. Client verbindenFüge den Server in Orynivo unter Einstellungen → Orynivo Server hinzu. Standardport: 5280.

Gut zu wissen

Häufige Fragen.

Ist Orynivo wirklich kostenlos?

Ja. Orynivo wird unter der Apache-Lizenz 2.0 veröffentlicht. Du kannst den Player kostenlos nutzen, prüfen und weiterentwickeln.

Welche Audioformate werden unterstützt?

Unter anderem FLAC, WAV, MP3, AAC, Ogg/Vorbis, Opus, MKA, DSF und unkomprimiertes DFF/DSDIFF. Die konkrete Decodierung hängt teilweise von FFmpeg ab.

Brauche ich Orynivo Server?

Nein. Für eine lokale Bibliothek reicht die Desktop-App. Der Server ist optional und macht eine zentrale Sammlung im lokalen Netzwerk für Orynivo-Clients verfügbar.

Sendet Orynivo meine Bibliothek in eine Cloud?

Nein. Bibliothek und Einstellungen bleiben lokal. Externe Dienste werden nur für ausdrücklich verwendete Funktionen wie Metadaten, Radio, Podcasts oder KI-Chat kontaktiert.

Wie erhalte ich Updates?

Orynivo kann signierte GitHub-Releases prüfen. Downloads und Installationen werden nur nach deiner ausdrücklichen Aktion gestartet. Diese Website liest ebenfalls ausschließlich die öffentliche GitHub-Release-API, um aktuelle Downloadlinks anzuzeigen.
