पाँच मिनट में तैयार

आपकी त्वरित शुरुआत।

डाउनलोड से पहले ट्रैक तक: स्थानीय संग्रह के लिए न खाते की ज़रूरत है, न सर्वर की।

विकी में विस्तृत मार्गदर्शिका ↗
  1. 1 मिनटइंस्टॉल करें और खोलें

    अपने ऑपरेटिंग सिस्टम का पैकेज डाउनलोड करें, Orynivo इंस्टॉल करें और ऐप शुरू करें।

  2. 1 मिनटसंगीत स्रोत जोड़ें

    सेटिंग्स → फ़ोल्डर खोलें और कम से कम एक स्थानीय संगीत फ़ोल्डर चुनें। इसके बदले या साथ में Orynivo सर्वर जोड़ सकते हैं।

  3. स्वचालितसंग्रह स्कैन करें

    स्कैन शुरू करें। सूचकांक बनते समय कलाकार, एल्बम, ट्रैक और मौजूद कवर क्रमशः दिखाई देंगे।

  4. 1 मिनटऑडियो आउटपुट जाँचें

    डिफ़ॉल्ट आउटपुट तुरंत काम करता है। ज़रूरत हो तो सेटिंग्स → आउटपुट में WASAPI, ASIO, ALSA, OpenAL या AirPlay चुनें।

  5. चलिए शुरू करेंपहला ट्रैक चलाएँ

    ट्रैक, एल्बम या कलाकार खोलें और ट्रैक पर डबल-क्लिक करें। वॉल्यूम, कतार और आउटपुट नीचे के प्लेयर में हमेशा उपलब्ध हैं।

प्लेटफ़ॉर्म के अनुसार इंस्टॉलेशन

आपके सिस्टम के लिए सही पैकेज।

  1. इंस्टॉलर डाउनलोड करेंवर्तमान win-x64-Setup.exe रिलीज़ से डाउनलोड करें।
  2. Orynivo इंस्टॉल करेंइंस्टॉलर चलाएँ और विज़ार्ड के निर्देशों का पालन करें। विकल्प के रूप में पोर्टेबल ZIP निकाल सकते हैं।
  3. संगीत जोड़ेंसेटिंग्स → संग्रह खोलें, संगीत फ़ोल्डर जोड़ें और स्कैन शुरू करें।
  4. आउटपुट चुनेंOrynivo डिफ़ॉल्ट आउटपुट चुनता है। बिट-परफ़ेक्ट प्लेबैक के लिए WASAPI Exclusive, ASIO या cwASIO कॉन्फ़िगर करें।
  1. पैकेज चुनेंDebian/Ubuntu के लिए DEB, Fedora/openSUSE के लिए RPM या Arch पैकेज उपयोग करें। पोर्टेबल टार आर्काइव भी उपलब्ध हैं।
  2. इंस्टॉल करेंsudo apt install ./orynivo_*.deb
    sudo dnf install ./orynivo-*.rpm
    sudo pacman -U ./orynivo-*.pkg.tar.zst
  3. ऑडियो तैयार करेंFFmpeg आवश्यक है। OpenAL संगत डिफ़ॉल्ट है; सीधा ALSA एक्सक्लूसिव आउटपुट और नेटिव DSD/DoP देता है।
  1. आर्किटेक्चर चुनेंM1 और नए Mac के लिए Apple Silicon, पुराने Mac के लिए Intel।
  2. PKG खोलेंहस्ताक्षरित रिलीज़ पैकेज खोलें और Orynivo को Applications में इंस्टॉल करें। पोर्टेबल ZIP और टार संस्करण भी उपलब्ध हैं।
  3. संग्रह स्कैन करेंसंगीत फ़ोल्डर जोड़ें। Orynivo सामान्य पैकेज-मैनेजर पथों और उपयोगकर्ता कैश में FFmpeg खोजता है।
  1. सर्वर पैकेज इंस्टॉल करेंLinux सिस्टम पर उपयुक्त DEB या RPM पैकेज इंस्टॉल करें।
  2. कॉन्फ़िगरेशन संपादित करेंAPI कुंजी और संग्रह पथ /etc/orynivo-server/appsettings.json में दर्ज करें। कुंजी सार्वजनिक रूप से साझा न करें।
  3. सेवा शुरू करेंsudo systemctl enable --now orynivo-server
  4. क्लाइंट जोड़ेंOrynivo में सेटिंग्स → Orynivo सर्वर के अंतर्गत सर्वर जोड़ें। डिफ़ॉल्ट पोर्ट: 5280.

अक्सर पूछे जाने वाले प्रश्न।

क्या Orynivo सचमुच निःशुल्क है?

हाँ। Orynivo Apache 2.0 लाइसेंस के अंतर्गत प्रकाशित है। आप प्लेयर निःशुल्क उपयोग कर सकते हैं, उसका कोड जाँच सकते हैं और उसे विकसित कर सकते हैं।

कौन-से ऑडियो प्रारूप समर्थित हैं?

FLAC, WAV, MP3, AAC, Ogg/Vorbis, Opus, MKA, DSF और असंपीड़ित DFF/DSDIFF सहित अनेक प्रारूप। सटीक डिकोडिंग समर्थन कुछ हद तक FFmpeg पर निर्भर है।

क्या मुझे Orynivo सर्वर चाहिए?

नहीं। स्थानीय संग्रह के लिए डेस्कटॉप ऐप पर्याप्त है। वैकल्पिक सर्वर स्थानीय नेटवर्क पर केंद्रीय संग्रह Orynivo क्लाइंट को उपलब्ध कराता है।

क्या Orynivo मेरा संग्रह क्लाउड में भेजता है?

नहीं। संग्रह और सेटिंग्स स्थानीय रहते हैं। बाहरी सेवाओं से केवल आपके द्वारा स्पष्ट रूप से उपयोग की गई सुविधाओं—जैसे मेटाडेटा, रेडियो, पॉडकास्ट या AI चैट—के लिए संपर्क किया जाता है।

अपडेट कैसे मिलते हैं?

Orynivo हस्ताक्षरित GitHub रिलीज़ जाँच सकता है। डाउनलोड और इंस्टॉलेशन केवल आपकी स्पष्ट कार्रवाई के बाद शुरू होते हैं। यह वेबसाइट भी वर्तमान डाउनलोड लिंक दिखाने के लिए केवल सार्वजनिक GitHub Releases API उपयोग करती है।

वेबसाइट का संचालन
वेबसाइट स्वयं संचालित Ubuntu सर्वर पर nginx से उपलब्ध कराई जाती है। पहुँचने पर एक्सेस और त्रुटि लॉग में तकनीकी रूप से आवश्यक कनेक्शन डेटा संसाधित होता है, विशेष रूप से IP पता, समय, माँगी गई फ़ाइल, भेजे गए डेटा की मात्रा, रेफ़रर और ब्राउज़र जानकारी। GDPR अनुच्छेद 6(1)(f) के अनुसार वैध हितों के आधार पर इसका उद्देश्य वेबसाइट का सुरक्षित और विश्वसनीय संचालन है। लॉग प्रतिदिन रोटेट होते हैं और 14 रोटेशन के बाद हटा दिए जाते हैं, इसलिए प्रविष्टियाँ अधिकतम लगभग 15 दिन रहती हैं। अधिक समय तक रखना केवल विशिष्ट सुरक्षा घटनाओं की जाँच या कानूनी दायित्व पूरा करने के लिए होता है।

Cloudflare
वेबसाइट की सुरक्षा और तेज़ वितरण के लिए Cloudflare रिवर्स प्रॉक्सी के रूप में उपयोग होता है। प्रदाता Cloudflare, Inc., 101 Townsend St, San Francisco, CA 94107, USA है। इसलिए कनेक्शन पहले Cloudflare के वैश्विक नेटवर्क से गुज़रते हैं। Cloudflare IP पते और अनुरोध के तकनीकी मेटाडेटा संसाधित कर सकता है। उपयोग GDPR अनुच्छेद 6(1)(f) के अंतर्गत सुरक्षित, विश्वसनीय और कुशल वितरण में हमारे वैध हित पर आधारित है। डेटा अमेरिका में भी संसाधित हो सकता है। Cloudflare इसके लिए EU मानक संविदात्मक धाराओं सहित संविदात्मक डेटा-सुरक्षा गारंटी देता है। अधिक जानकारी यहाँ है: Cloudflare की गोपनीयता नीति ↗.

वर्तमान संस्करण और डाउनलोड लिंक दिखाने के लिए ब्राउज़र सार्वजनिक GitHub Releases API से अनुरोध करता है। तकनीकी रूप से आवश्यक कनेक्शन डेटा GitHub को भेजा जाता है। यह भी लागू होता है: GitHub की गोपनीयता सूचना ↗.
