Listo en minutos

Instalación y primeros pasos.

Guía completa en la wiki ↗
  1. Descargar el instaladorDescarga el archivo actual win-x64-Setup.exe desde la versión.
  2. Instalar OrynivoEjecuta el instalador y sigue el asistente. También puedes extraer el ZIP portátil.
  3. Añadir músicaAbre Ajustes → Biblioteca, añade tus carpetas de música e inicia el escaneo.
  4. Elegir una salidaOrynivo selecciona una salida predeterminada. Para reproducción bit-perfect, configura WASAPI Exclusive, ASIO o cwASIO.
  1. Elegir un paqueteUsa DEB para Debian/Ubuntu, RPM para Fedora/openSUSE o el paquete de Arch. También hay archivos portátiles.
  2. Instalarsudo apt install ./orynivo_*.deb
    sudo dnf install ./orynivo-*.rpm
    sudo pacman -U ./orynivo-*.pkg.tar.zst
  3. Preparar el audioSe requiere FFmpeg. OpenAL es la opción compatible; ALSA directo permite salida exclusiva y DSD/DoP nativo.
  1. Elegir arquitecturaApple Silicon para M1 y posteriores, Intel para Macs antiguos.
  2. Abrir el PKGAbre el paquete firmado e instala Orynivo en Aplicaciones. También hay versiones ZIP y tar portátiles.
  3. Escanear la bibliotecaAñade carpetas de música. Orynivo busca FFmpeg en rutas habituales de gestores de paquetes y en la caché del usuario.
  1. Instalar el paquete del servidorInstala el paquete DEB o RPM adecuado en un sistema Linux.
  2. Editar configuraciónIntroduce la clave API y las rutas de biblioteca en /etc/orynivo-server/appsettings.json . No compartas la clave públicamente.
  3. Iniciar el serviciosudo systemctl enable --now orynivo-server
  4. Conectar el clienteAñade el servidor en Orynivo en Ajustes → Orynivo Server. Puerto predeterminado: 5280.

Conviene saber

Preguntas frecuentes.

¿Orynivo es realmente gratis?

Sí. Orynivo se publica con licencia Apache 2.0. Puedes usar, estudiar y desarrollar el reproductor gratis.

¿Qué formatos de audio son compatibles?

Incluye FLAC, WAV, MP3, AAC, Ogg/Vorbis, Opus, MKA, DSF y DFF/DSDIFF sin comprimir. La compatibilidad exacta depende en parte de FFmpeg.

¿Necesito Orynivo Server?

No. La aplicación de escritorio basta para una biblioteca local. El servidor opcional permite acceder a una colección central desde clientes Orynivo en la red local.

¿Orynivo envía mi biblioteca a la nube?

No. La biblioteca y los ajustes permanecen locales. Solo se contacta con servicios externos para funciones que usas expresamente, como metadatos, radio, pódcasts o chat de IA.

¿Cómo recibo actualizaciones?

Orynivo puede comprobar versiones firmadas de GitHub. Las descargas e instalaciones solo comienzan tras una acción explícita. Esta web usa únicamente la API pública de GitHub Releases para mostrar enlaces actuales.

Los registros rotan a diario y se eliminan después de 14 rotaciones, por lo que las entradas se conservan durante un máximo aproximado de 15 días.
