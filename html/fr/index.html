Prêt en cinq minutes

Votre démarrage rapide.

Du téléchargement au premier titre : une bibliothèque locale ne nécessite ni compte ni serveur.

Guide complet dans le wiki ↗
  1. 1 minuteInstaller et ouvrir

    Téléchargez le paquet correspondant à votre système, installez Orynivo et lancez l’application.

  2. 1 minuteAjouter une source musicale

    Ouvrez Réglages → Dossiers et sélectionnez au moins un dossier musical local. Vous pouvez aussi connecter un serveur Orynivo à la place ou en complément.

  3. AutomatiqueAnalyser la bibliothèque

    Lancez l’analyse. Les artistes, albums, titres et pochettes existantes apparaissent progressivement pendant l’indexation.

  4. 1 minuteVérifier la sortie audio

    La sortie par défaut fonctionne immédiatement. Dans Réglages → Sortie, vous pouvez choisir WASAPI, ASIO, ALSA, OpenAL ou AirPlay si nécessaire.

  5. C’est partiLire votre premier titre

    Ouvrez Titres, Albums ou Artistes et double-cliquez sur un titre. Le volume, la file d’attente et la sortie restent accessibles dans le lecteur inférieur.

Installation selon la plateforme

Le paquet adapté à votre système.

  1. Télécharger l’installateurTéléchargez le fichier actuel win-x64-Setup.exe depuis la version.
  2. Installer OrynivoLancez l’installateur et suivez l’assistant. Vous pouvez aussi extraire le ZIP portable.
  3. Ajouter de la musiqueOuvrez Réglages → Bibliothèque, ajoutez vos dossiers musicaux et lancez l’analyse.
  4. Choisir une sortieOrynivo sélectionne une sortie par défaut. Pour une lecture bit-perfect, configurez WASAPI Exclusive, ASIO ou cwASIO.
  1. Choisir un paquetUtilisez DEB pour Debian/Ubuntu, RPM pour Fedora/openSUSE ou le paquet Arch. Des archives portables sont également disponibles.
  2. Installersudo apt install ./orynivo_*.deb
    sudo dnf install ./orynivo-*.rpm
    sudo pacman -U ./orynivo-*.pkg.tar.zst
  3. Préparer l’audioFFmpeg est requis. OpenAL est la solution compatible par défaut ; ALSA direct permet la sortie exclusive et le DSD/DoP natif.
  1. Choisir l’architectureApple Silicon pour les M1 et modèles récents, Intel pour les Mac plus anciens.
  2. Ouvrir le PKGOuvrez le paquet signé et installez Orynivo dans Applications. Des versions ZIP et tar portables sont également disponibles.
  3. Analyser la bibliothèqueAjoutez vos dossiers musicaux. Orynivo recherche FFmpeg dans les chemins habituels des gestionnaires de paquets et le cache utilisateur.
  1. Installer le paquet serveurInstallez le paquet DEB ou RPM approprié sur un système Linux.
  2. Modifier la configurationSaisissez la clé API et les chemins de bibliothèque dans /etc/orynivo-server/appsettings.json . Ne partagez pas cette clé publiquement.
  3. Démarrer le servicesudo systemctl enable --now orynivo-server
  4. Connecter le clientAjoutez le serveur dans Orynivo sous Réglages → Orynivo Server. Port par défaut : 5280.

Bon à savoir

Questions fréquentes.

Orynivo est-il vraiment gratuit ?

Oui. Orynivo est publié sous licence Apache 2.0. Vous pouvez utiliser, examiner et développer gratuitement le lecteur.

Quels formats audio sont pris en charge ?

Notamment FLAC, WAV, MP3, AAC, Ogg/Vorbis, Opus, MKA, DSF et DFF/DSDIFF non compressé. La prise en charge exacte dépend en partie de FFmpeg.

Ai-je besoin d’Orynivo Server ?

Non. L’application de bureau suffit pour une bibliothèque locale. Le serveur optionnel rend une collection centrale accessible aux clients Orynivo du réseau local.

Orynivo envoie-t-il ma bibliothèque dans le cloud ?

Non. Bibliothèque et réglages restent locaux. Les services externes ne sont contactés que pour les fonctions utilisées explicitement, comme les métadonnées, la radio, les podcasts ou le chat IA.

Comment obtenir les mises à jour ?

Orynivo peut vérifier les versions GitHub signées. Téléchargements et installations ne démarrent qu’après votre action explicite. Ce site utilise uniquement l’API publique GitHub Releases pour afficher les liens actuels.

Les journaux sont renouvelés chaque jour et supprimés après 14 rotations ; les entrées sont donc conservées au maximum pendant environ 15 jours.
