Installation & first steps.

Full guide in the wiki ↗
  1. Download the installerDownload the current win-x64-Setup.exe from the release.
  2. Install OrynivoRun the installer and follow the wizard. Alternatively, extract the portable ZIP.
  3. Add musicOpen Settings → Library, add your music folders and start the scan.
  4. Choose an outputOrynivo selects a default output. For bit-perfect playback, configure WASAPI Exclusive, ASIO or cwASIO.
  1. Choose a packageUse DEB for Debian/Ubuntu, RPM for Fedora/openSUSE or the Arch package. Portable tarballs are also available.
  2. Installsudo apt install ./orynivo_*.deb
    sudo dnf install ./orynivo-*.rpm
    sudo pacman -U ./orynivo-*.pkg.tar.zst
  3. Prepare audioFFmpeg is required. OpenAL is the compatible default; direct ALSA enables exclusive output and native DSD/DoP.
  1. Choose architectureApple Silicon for M1 and newer, Intel for older Macs.
  2. Open the PKGOpen the signed release package and install Orynivo in Applications. Portable ZIP and tar versions are also available.
  3. Scan your libraryAdd music folders. Orynivo looks for FFmpeg in common package-manager paths and the user cache.
  1. Install the server packageInstall the matching DEB or RPM package on a Linux system.
  2. Edit configurationEnter the API key and library paths in /etc/orynivo-server/appsettings.json . Do not share the key publicly.
  3. Start the servicesudo systemctl enable --now orynivo-server
  4. Connect the clientAdd the server in Orynivo under Settings → Orynivo Server. Default port: 5280.

Good to know

Frequently asked questions.

Is Orynivo really free?

Yes. Orynivo is released under the Apache 2.0 license. You may use, inspect and develop the player for free.

Which audio formats are supported?

Including FLAC, WAV, MP3, AAC, Ogg/Vorbis, Opus, MKA, DSF and uncompressed DFF/DSDIFF. Exact decoding support partly depends on FFmpeg.

Do I need Orynivo Server?

No. The desktop app is enough for a local library. The optional server makes a central collection available to Orynivo clients on your local network.

Does Orynivo send my library to the cloud?

No. Your library and settings remain local. External services are contacted only for features you explicitly use, such as metadata, radio, podcasts or AI chat.

How do I get updates?

Orynivo can check signed GitHub releases. Downloads and installations start only after your explicit action. This website also uses only the public GitHub Releases API to show current download links.
